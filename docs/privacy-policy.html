Emblem Cards — Privacy Policy

Last updated: 2026-04-13

Emblem Cards ("the app") is built with user privacy as a core design goal. This page describes exactly what data the app handles.

What we collect

On-device only (not transmitted):

  • A randomly-generated player ID (UUID) created on first launch.
  • Your chosen display name (defaults to Player-XXXX).
  • Your saved deck, in-progress match state, win/loss record, and settings.

All of the above is stored locally using Android's AsyncStorage. Uninstalling the app removes this data. Using the "Reset identity" button in Settings clears it manually.

Data sent over the network

The app only makes network requests when you use Online multiplayer. In that mode:

  • Your player ID and display name are sent to the server you configured.
  • Your in-game actions (deploy, attack, end turn) are sent to the server so your opponent's client can render them.
  • The server URL you use is one you choose in Settings — there is no default third-party backend.

Offline modes (Quick Start, VS Computer, Local 2P) do not make any network requests.

What we do not collect

  • No email, phone number, contacts, or other personal information.
  • No location, camera, microphone, or device identifiers (no advertising ID, no IMEI).
  • No crash-reporting SDK or third-party analytics.
  • No ads.

Permissions

The app requests:

  • INTERNET — only used for Online multiplayer connections to the server URL you configure.
  • VIBRATE — for haptic feedback on game events; can be disabled in Settings.

Children's privacy

The app does not knowingly collect information from children. Because we do not collect personal information from any user, children included, no separate handling is needed.

Changes

If this policy is updated, the "Last updated" date above will change. Substantive changes will be accompanied by an in-app notice.
